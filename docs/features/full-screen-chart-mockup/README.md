# Full-screen chart mockup

A single HTML page (open `index.html` in a browser) with synthetic data. Every stock chart
gets an expand button that opens a dark, full-window chart: the stock and SPY (or a sector
ETF) on their own price axes, bar sizes 1m / 5m / 15m / 1h / 1D, crosshair and data window,
volume against the 20-session average, optional session VWAP, and the alert window shaded when
opened from an alert. Reference only, not application code.

Published design: https://claude.ai/artifact/YQ23XqBJCKCsSXbJi5pubd
