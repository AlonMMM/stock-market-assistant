# Option ticket mockups

Design-canvas artboards (`.dc.html`, need the canvas runtime `support.js`) with sample data;
`canvas.json` is the canvas index. Reference only, not application code.

- `Main.dc.html`: A, stacked ticket (as built in PR #103).
- `TicketSplit.dc.html`: B, broker split, chain on the left and the order panel on the right.
- `TicketPhone.dc.html`: C, phone bottom sheet.
- `VolumeColumn.dc.html` / `VolumeBar.dc.html`: the watchlist's volume column, plain and against
  a typical day.

Published design: https://claude.ai/artifact/FwqfDYtPLKWWQYnR9d5QqV
