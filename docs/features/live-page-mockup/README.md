# Live page mockup source

Design-canvas artboards (`.dc.html`) for [the live page spec](../live-page.md). All market
numbers are SAMPLE data generated in each file's script. `Main.dc.html` is the
interactive desktop page (Alerts and Watchlist tabs); `Watchlist.dc.html` opens it on the
Watchlist tab; `Phone.dc.html` and `Status.dc.html` are static. They need the design
canvas runtime (`support.js`) and are reference only, not application code.
